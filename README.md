# ([LeetCode Mastery](https://leetcodemastery.vercel.app/))

Algorithmic pattern coach built with React + Vite + Tailwind CSS and powered by Gemini.

## How this was made

Made using my knowledge gained from a coursera certificate course Google AI for profesionals. Went through a bunch of phases for the prompts to make this. 

## What its for

Its mostly for my own use, and if/when publicized its going to be for anyone to use. Uses a low tier api key i beleive from google gemini so wont be too fast, but this is mostly a learning tool. I get lost doing these problems and thought "I want to have something centralized where i can see explanations for a problem im doing, have a quick little check to see if im understanding this properly, and then attempt the problem as if i were in an interview". Its graded using some gemini models, so if you are using this, check your work outside of this app please, always double check. 

Since this is made via AI, keep in mind response or feedback may not be accurate.... After my own use ill update this again with a 'review' of sorts.
